Pathix for Dynamics 365

The extension explains the fields on the Dynamics 365 forms you open. It reads only the names of tables and columns, never their values.

Without a Pathix address it runs in Lite: cards read Dataverse metadata as you and show what is registered or declared. With your organization's Pathix address, cards show what Pathix found actually writes each field.

Power Platform admin center

Adds who holds a security role, and the findings that name it, to the role pages. Adds a count to each role in the role list and a chip to each application user. It needs your Pathix address and a sign-in.

Turning it on asks the browser for access to admin.powerplatform.microsoft.com and nothing else. The extension reads only the ids in the page address and the Application IDs in the application user grid. It reads no names, emails, tokens or cookies, and the page itself makes no network calls. Reload open admin center tabs after you change this.
